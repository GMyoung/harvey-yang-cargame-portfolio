# Harvey Yang Car Game Portfolio

An experimental 3D portfolio for Harvey Yang, adapted from Bruno Simon's MIT-licensed `folio-2025` project.

Drive through the world to explore Harvey's software engineering, AI automation, business analytics, and full-stack project work.

## Setup

Create a `.env` file based on `.env.example`, then run:

```bash
npm install --force
npm run dev
```

Build for production:

```bash
npm run build
```
